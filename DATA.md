# Data access

The analysis uses the licensed CSMAR dataset stored locally as `csmar_0110sample.dta`. The dataset is not included in this repository and must be obtained independently under an appropriate CSMAR license.

Expected variables include stock identifier, year, month, monthly return, market capitalization, book-to-market ratio, profitability, momentum, turnover, short-term reversal, beta, and Fama–French-based idiosyncratic volatility.
